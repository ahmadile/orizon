# Orizon - Déploiement V1

## 🧪 Laboratoire de développement logiciel

Orizon est une plateforme agentique qui permet de :
- Analyser des projets open source en profondeur
- Forker des projets intelligemment
- Générer des fichiers de contexte pour d'autres agents
- Utiliser l'agent IA intégré pour modifier le code directement

## 🚀 Déploiement

- Base de données : Neon (PostgreSQL)
- Hébergement : Vercel
